# 设计之道（TaoDown）

TaoDown 的设计依据道家思想，由内到外分为四层功夫。

## 一、本体纯一（内核）
道生一：产品只有一个本体——下载。凡与下载无必然关系的（网盘聚合、账号管理），
一律不进内核。本体越纯，行为越可预期，维护越省心。
- 引擎只有两件：aria2-next（HTTP/BT/磁力/ed2k）与 aria2c（FTP）。
- 服务层只有任务模型、队列、分类、链接解析、Native Messaging 帧协议。

## 二、删繁就简（结构）
大道至简：界面只剩两页——下载、设置。设置项按生活语言分组归块，
每块有一句话说明，用户不必猜。

## 三、随象而变（外观）
三象（水墨/天灰/墨夜）= 三字典，键集完全一致，同键同义不同值；
控件消费的每一个键都须在字典里真实给出（禁 ThemeDictionaries 分段），
换肤入口唯一 ThemeService.Apply，大面直涂不赌资源重估时机。

## 四、无为而治（体验）
上善若水：下载如水，顺其自然——
- 后台自动：剪贴板复制即待命、浏览器下载自动转交、退出后托盘继续下载；
- 不强求：能自动分类的不让用户选目录两次；能断点续传的不让用户从头再来；
- 不越界：流媒体分片（m3u8/ts/mpd）与 blob:/data: 临时链接不接管，如实相告。

## 治事三诀（开发纪律）
1. 知常曰明：兜底文案禁把"未定"说成"已坏"，状态三档如实。
2. 图难于其易：构建自检从包内存在到安装落点逐层设卡，问题在源头拦截。
3. 千里之行：每次交付前全量测试、真机可复核，不以"看起来能跑"为足。
