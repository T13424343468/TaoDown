# BROWSER-EXTENSION：接管浏览器下载

批次五新增，v2.50 起为「零配置零操作」：安装 TaoDown 后**重启浏览器即自动挂载插件**，什么都不用点。在 Chrome / Edge / Brave / Vivaldi / Chromium 等内核浏览器里点任何下载，都会转交给 TaoDown：弹出保存位置（默认选中设置页的下载根目录），确认后由 TaoDown 接管下载。

## 自动挂载（默认主路，零操作）

1. 安装 TaoDown（MSI 安装器）——安装器直接把插件外链登记写进系统（机器级 + 用户级），**无需启动 TaoDown、无需管理员操作**；同时主程序首次启动会再登记一遍宿主注册（免管理员）。
2. 重启浏览器（或重启电脑后打开浏览器）。扩展自动出现——插件包是已签名 CRX，走系统级外链登记，不依赖开发者模式。
3. 点任何下载即由 TaoDown 接管；点浏览器里的 TaoDown 扩展图标可查看连接状态（绿色 ✓ /「已连接」即接通）。

覆盖的登记位置：Chrome、Edge、Chromium、Brave（两键）、Vivaldi、Opera、Yandex（两键）、夸克（三键）、360 安全/极速（各两键）。64 位 Windows 额外写 Chrome/Edge 的 Wow6432Node 键。键组唯一来源 `tools/extension/registry_paths.json`，安装包、主程序、单元测试三方交叉校验一致。

### 升级说明（v2.50 起换新签名钥匙）

插件签名私钥未存档被迫换新，扩展 ID 从旧 `mhb…` 变为新 `dchnmdakoleaofgpkhddhmohcoomlimp`。升级后：

- 浏览器重启后新版插件自动挂载，旧登记键被安装器与主程序自动清干净，不会重复接管。
- **唯一需要你动手的一步**：如果你此前手动加载过旧版插件（夸克等），请在扩展页里把旧的那份「TaoDown 接管助手」移除一次——新版挂载后两个副本会同时存在。
- 旧版插件的连接通道保留兼容（宿主同时放行新旧两个 ID），移除旧副本前的下载不会被丢。

## 手动加载（仅夸克 / 360 等少数内核）

这些内核不认系统级自动挂载，只认开发者模式加载（一次即可）：

1. 先装好 TaoDown 并启动一次（完成宿主注册）。
2. 打开对应扩展管理页：
   - 夸克：`quark://extensions/?entry=mainmenu`（真机确证：直接输 `quark://extensions` 会打开空白新标签页，必须带 `?entry=mainmenu`），页面左下角开「开发者模式」。
   - 360 安全：`se://extensions`；360 极速：`chrome://extensions`。
3. 点「加载已解压的扩展程序」→ 选安装目录下的 `extension` 文件夹。
4. 若扩展页没有「开发者模式」开关：夸克右上角菜单 →「设置」→「关于夸克」→ 连续快速点击版本号进入开发者选项，开启「允许加载未签名扩展」后重试本页。
5. 点扩展图标查看连接状态；首次启动 TaoDown 时也会弹引导窗，「打开扩展页」按钮直达对应内核的插件管理页。

## 注意事项

- `blob:` / `data:` 开头的链接是网页内部生成的临时地址，离开页面就失效——TaoDown 插件可以直接接管：插件在页面内抓取内容分块回传、后台解码分块，由宿主落盘后弹保存框（v2.12 起支持；未启动 TaoDown 时浏览器照常自己下载）。
- 网页里点下载若跳出的链接是 `http/https` 才会转交 TaoDown；流媒体分片（m3u8/ts/mpd）始终放行给浏览器。
- **主程序没开也能接管**：点下载的请求会先落进收件箱，下次启动 TaoDown 时自动补弹保存框，不会丢（v2.50 新增存量扫描；此前关着 TaoDown 点下载等于白点）。

## 工作原理

- 浏览器开始下载时，插件先向宿主发 `precheck` 询问接管是否开启（v2.50，接管开关的唯一真相在 TaoDown 设置页，插件不再自存开关）：开着→经 `downloads.onDeterminingFilename` 拦截并取消浏览器内置下载，把地址、来源页、建议文件名通过 Native Messaging 发给本机 `TaoDown.Host.exe`；关着→放行浏览器自下，绝不多手。
- `blob:` 链接走专门的页面内抓取通道：内容脚本读取页面里的数据流，按 512KB 分块回传宿主落盘；`data:` 链接由插件后台直接解码分块。两条通道均等待宿主逐条回执后才断开，收尾消息不会丢失。
- 宿主校验协议（仅放行 http/https/ftp/magnet/ed2k）后把请求写入 TaoDown 收件箱；主程序弹出保存位置对话框，默认定位到设置页「下载根目录」，可改成任意文件夹。同一请求 3 秒内重复到达会被内容级去重拦下（新旧插件短暂并存、个别内核双回调都不弹两个框）。
- 确认后任务进入 TaoDown 队列，享受多线程分段、断点续传、自动分类。
- 链接上右键 →「用 TaoDown 下载」可直接接管，无需先开始浏览器下载。
- 插件与扩展 ID 绑定（manifest 内置 key，当前 ID 为 `dchnmdakoleaofgpkhddhmohcoomlimp`，v2.50 起换新钥匙；旧 ID 保留在宿主 allowed_origins 兼容过渡），宿主注册只允许放行的扩展调用。
- 登记的 `path` 直指安装目录里的 `extension\taodown.crx`（已签名插件包，v2.50 起；此前的目录型 path 只有 Chrome 认，Edge 官方文档明确要求指向打包文件）。安装包在 MSI 安装期写机器级登记，卸载随组件自动清除；主程序启动时写用户级登记兜底。

## 边缘情况

- 流媒体分片（m3u8 / ts / mpd）不接管，仍由浏览器处理（网站播放器依赖这些分片）。
- 下载点击时浏览器可能已经下了几百 KB 才被取消，属正常现象。
- 未启动 TaoDown 主程序时插件无法转发，请求会落收件箱待启动后交付；图标可能显示红色「!」。
- 在 TaoDown 设置页关闭「浏览器接管」后，所有下载恢复浏览器默认行为（precheck 实时应答，无需重启浏览器）。
- 只接管用户主动点击产生的下载，插件不访问任何网页内容。
