把 TaoDown 接进浏览器（v2.50：装完即用）

装好 TaoDown（v2.50 及以上）后，重启浏览器即可自动挂载插件——什么都不用点。之后在浏览器里点下载，会自动弹出保存位置并由 TaoDown 接管下载。

自动挂载（默认主路）

  1. 安装 TaoDown（安装器已把插件登记写进系统，装完即生效，无需先启动 TaoDown）。
  2. 重启浏览器（Chrome / Edge / Brave / Vivaldi / Chromium 等都认）。
  3. 扩展图标自动出现。点开图标：绿色 ✓ = 已接通；红色 ! = 重启 TaoDown 再试。
  4. 点任何下载即由 TaoDown 接管。主程序没开也没关系：请求会先落进收件箱，下次启动 TaoDown 时自动补弹保存框，不会丢。

升级说明（旧版 TaoDown → v2.50）

v2.50 换了新签名钥匙，扩展 ID 变更：

  • 浏览器重启后新版插件自动挂载，旧的系统登记已被安装器自动清干净。
  • 只有一步要你动手：如果此前在扩展页手动加载过旧版「TaoDown 接管助手」（夸克等内核常见），请把旧的那份移除一次，避免新旧两个插件同时接管。

手动加载（仅夸克 / 360 等少数内核）

这些内核不认系统级自动挂载，只认开发者模式加载（一次即可）：

  1. 先装好 TaoDown 并启动一次（完成宿主注册）。
  2. 夸克：地址栏输入 quark://extensions/?entry=mainmenu（真机确证：直接输 quark://extensions 会打开空白新标签页），页面左下角开「开发者模式」。
  3. 若扩展页没有「开发者模式」开关：夸克右上角菜单 →「设置」→「关于夸克」→ 连续快速点击版本号约 7 次，出现「已进入开发者模式」→ 开发者选项里开启「允许加载未签名扩展」（若有「扩展支持」开关一并开启）。
  4. 点「加载已解压的扩展程序」，选择安装目录下的 extension 文件夹（默认 C:\Program Files\TaoDown\extension）。
  5. 360 安全浏览器地址栏输入 se://extensions（社区教程确证）；360 极速浏览器输入 chrome://extensions，同样开「开发者模式」加载。

哪些浏览器支持？

  • 自动挂载：Chrome、Edge、Chromium、Brave、Vivaldi、Opera、Yandex（重启浏览器即挂载）。
  • 需手动加载一次：夸克、360 安全、360 极速（内核只认开发者模式）。
  • 暂不支持：Firefox（插件协议不同）。

常见问题

图标显示红色 !：宿主没连上。先确认 TaoDown 在运行，再重启浏览器重试；仍不行请把启动日志（%LOCALAPPDATA%\TaoDown\logs\startup.log）发给开发者。

blob: 开头的链接不接管：那是网页内部生成的临时地址，离开页面就失效，任何下载器都无法使用；浏览器会照常自己下载。

关闭「浏览器接管」：开关在 TaoDown 主程序设置页（v2.50 起扩展弹窗不再放开关，避免两处开关打架）。关掉后所有下载立即恢复浏览器默认行为，无需重启浏览器；重新打开同理。
